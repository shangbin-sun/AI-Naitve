# 项目中心体验改版验收

日期：2026-09-07。本轮交付项目筹备体验，不代表任务执行闭环已实现。

## 实施范围

- 全局只有项目、员工两个入口。项目默认首页，员工入口弱化；移除独立团队设计和最近团队导航。
- 创建时持久保存项目及原始目标，后续对话、方案和员工均在同一个项目内修改。
- 项目内提供概览、对话、方案、历史全宽视图，不固定平分屏幕。
- 原 Design 表承接持续项目，Project 表承接历史方案快照；保留原 ID、表及旧 API，不复制或删除原内容。
- 新 API `/workspaces` 和 `/snapshots`（均以 `/api` 为前缀）。旧 `/designs`、`/projects` 保持兼容。
- 未完成方案中的 AI 员工也生成可编辑工程。
- 项目标签和员工详情可通过 URL 恢复，浏览器返回支持标签恢复；离开未保存编辑有保护。
- 修复首次创建后快速请求失败时，初始化 effect 清掉错误提示的竞态；创建成功后立即更新项目列表。
