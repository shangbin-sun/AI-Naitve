# 主智能体与子智能体运行改造清单

2026-09-10。已实施并验证；范围：本地 AI 工作室，不包含 Kubernetes 部署。详见 [验收记录](native-runtime-validation.md)。

## 产品与数据

- [x] 产品方案同步：项目公共定义与执行数据分离；两个任务入口，共用运行体验。
- [x] 技术方案同步：主会话调度原生子智能体，平台校验依赖和持久化状态。
- [x] definition 内容寻址快照包含员工文件、工作流、参考资料和附件；运行固定快照。
- [x] node-tasks / workflow-tasks 的 task/run/node/attempt 结构完全对齐。
- [x] 时间戳、可读短名、随机后缀构成任务与运行 ID。
- [x] 新表与旧表并存；旧任务、代码验证、下载和聊天保持兼容。

## 运行与工具

- [x] 每项目独立管理工作目录；管理会话持续复用。
- [x] 每个运行独立主会话；员工由原生 spawn/wait 调度，记录真实子会话 ID。
- [x] 文件直接读取；项目定义修改仍经版本校验 API/MCP。
- [x] 运行状态工具绑定实际调用会话；不能用模型传入的项目 ID 扩权。
- [x] 前置依赖、重复提交、人工节点、结果路径及完成条件由平台验证。
- [x] 单节点不自动运行上游；由用户提供输入。
- [x] 取消、重启中断、原会话恢复不自动重放已完成节点。
- [x] 输出、交接、日志、人工答复归档；界面可查看状态和成果。

## 验收

- [x] 单节点及串并行工作流运行。
- [x] 运行期间编辑公共定义不改变旧快照；新运行得到新快照。
- [x] 跨项目路径、目录穿越、符号链接、未完成依赖、伪造子会话被拒绝。
- [x] 重复请求、取消、恢复、人工处理回归。
- [x] 后端全量测试、前端测试、生产构建。
- [x] 本机 Codex 原生子智能体实际测试；记录与模拟测试分别说明。

兼容边界：旧 employee.py 与代码交付记录作为既有执行类型保留，不将它们改名冒充原生子智能体运行。文件系统写权限以整个 run 为边界；同一 run 内的子智能体是协作关系，不能宣称原生子智能体天然具有各自的操作系统沙箱。
