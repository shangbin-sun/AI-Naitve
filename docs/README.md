## v0.3 主要变化

1. 对话式团队设计成为主要创建入口，基础自动创建提升为 P0。
2. 聊天生成岗位、工作流、输入输出与人工决策点，优先引用现有员工，缺失能力生成工程草稿。
3. 创建后通过待完善清单进入员工开发，支持继续聊天和手动修改，保留版本与差异。
4. 区分自动创建草稿、正式发布和实际运行；验收场景扩充至 30 项。

## v0.2 主要变化

1. 明确员工工厂是平台内独立开发子系统，拥有源工程、环境、调试、评测和发布流程。
2. 分开员工工程、员工模板版本、能力入口、工作流程、项目模板与项目实例。
3. 员工开发、基础项目模板、输入契约、工具就绪检查和资产导入导出进入建议首版范围。
4. 加入结构化人工表单、评审返工、两级运行视图和需求文件同步规则。
5. 验收场景由 14 项扩充为 24 项；保留待确认项，尚未开始实施。
